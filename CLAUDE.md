# Staylong

Verified long-stay Thailand directory at staylong.co. Next.js App Router, TypeScript strict, Tailwind, pnpm 9, Supabase (Singapore, ref `fbopazqtgbukzdgbwlzf`), Vercel.

## Commands

`pnpm dev`, `pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm build`. Migrations live in `supabase/migrations` (0001 to 0037). `scripts/db-smoke.sh` applies them to plain Postgres and runs `supabase/tests/smoke.sql`; CI runs it on every push.

## Layout

- `src/app/` public pages. English only. UI copy lives in `src/lib/copy.ts`.
- `src/lib/data.ts` read model (anon key, views from 0018). `src/lib/supabase/admin.ts` service role, server only.
- `src/lib/checker/engine.ts` pure checker. Thresholds come from `rules`, never from code.
- `src/lib/actions/` server actions call the public write functions from 0026 (`subscribe`, `submit_lead`, `save_checker_result`, `get_checker_result`) and 0033 (`confirm_subscription`, `unsubscribe`) with the publishable key.
- Lead routing and email outbox (D33): every email is queued in `outbox` by a database function and sent by the Edge Function `supabase/functions/outbox` (verify_jwt off, Resend). `submit_lead` calls `after_lead_submitted`, which qualifies the lead (30-day duplicate check), sends it to up to 3 matching Verified providers with an email address (`route_lead`, `provider_types_for`), and emails the person and the team. Providers answer at `/lead/<token>` (`get_delivery`, `respond_to_delivery`); contact details only after accepting (D10). pg_cron: `lead_followups` hourly (12 h reminder, 24 h team alert, retry waiting leads 14 days), `outbox` every 5 minutes, `apply_retention` daily. Team emails go to `ops_email()` (hello@staylong.co).
- Privacy (D34): `/privacy`, `/terms`, `/about`, `/disclosures`, `/privacy/request` (`submit_privacy_request`), `/for-providers` claim form (`submit_provider_claim`). Erase a person with `select public.erase_person('email')` in the SQL editor.
- Email (D27): `supabase/functions/send-confirmation` (Deno, verify_jwt off) sends the double opt-in email through Resend with the service role and `claim_confirmation_email`. `src/lib/email/confirmation.ts` calls it after a subscribe. Pages `/subscribe/confirm` and `/unsubscribe` confirm with a button (mail scanners prefetch links); `/api/unsubscribe` is the RFC 8058 one-click target. `RESEND_API_KEY` lives in Supabase Edge Function secrets, not Vercel.
- `src/lib/tools.ts` + `src/components/tools/` free tools at `/tools/<slug>`; each has an answer, FAQs, WebApplication schema and an `EmailCapture` lead magnet. `src/content/faq.ts` feeds `/faq`; `src/content/countries.ts` feeds `/visas-for/<country>`.
- `src/content/` editorial layer: `guides/*.ts` (Guide) render at `/guides/<slug>`, `visas/<track>.ts` (VisaContent) render inside `/visa-rules/<slug>`. Register new files in `src/content/index.ts`. Writing rules: see `docs/editorial-brief.md`; research in `docs/research/`.
- Places: `src/content/places.ts` (28 places) and `src/content/immigration-offices.ts` (20 offices) render at `/places/<slug>` and `/immigration-offices/<slug>`. POIs come from `src/content/data/pois.json`, written by `.github/workflows/pois.yml` (OpenStreetMap via Nominatim, monthly). Maps use `src/components/map/poi-map.tsx` (MapLibre).
- Schools pipeline: `scripts/apify/*` run by `.github/workflows/schools.yml` (manual). Areas, search phrases and the category classifier live in `scripts/apify/lib.ts`; each area is one Apify run with `locationQuery`, so results are not capped per search. Types: language_school, muay_thai_camp, visa_agent, cooking_school, massage_school. Scrape Google Maps, import, fetch site text, then apply quoted facts written per `data/schools/brief.md`.
- MCP server: `src/app/mcp/route.ts` (Streamable HTTP, stateless, read-only) with tools in `src/lib/mcp/tools.ts` and a search corpus in `src/lib/mcp/corpus.ts`. Docs at `/mcp-server`, card at `/.well-known/mcp/server-card.json`. Registry entry `server.json`, published by `.github/workflows/mcp-registry.yml` (runs when `server.json` changes, GitHub OIDC). Bump its version before each publish. Listed as `io.github.Timgrassin/staylong`.
- Local design previews without Supabase: `STAYLONG_FIXTURES=1 pnpm dev` (FAKE providers, real seeded rules).
- Design tokens in `src/app/globals.css` `:root`, values from `handoff/design/html/yuu.css` (D26). Font: Anuphan via next/font. `accent` (turmeric) is for fills and icons only; text on `accent-soft` uses `warn`. Register new color tokens in `src/lib/cn.ts`. Screen designs: `handoff/design/screenshots/`, brief: `handoff/START-HERE.md`.

## SEO and AI search

Every public page follows `docs/seo.md`. Use `pageMetadata()` for metadata, `graph()` builders for JSON-LD, and `AnswerBlock` above the fold. Never index previews. Never show a date that is not from the database. Internal links come from `src/lib/seo/related.ts` (rendered by `RelatedLinks`); `related.test.ts` guards the link graph. Long Supabase lists go through `all()` in `src/lib/data.ts` (PostgREST caps a request at 1,000 rows).
